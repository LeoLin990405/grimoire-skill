# 不要直接用本 skill — 走 mineru-local

2026-04-27 起，本 skill 的 trigger 词全部归 `mineru-local`。

**用户对话**：永远从 `mineru-local` 入口（`pdf2md` helper 自动路由 local / cloud）

**本 skill 仅作 helper 仓库保留**：
- `scripts/mineru-parse.sh` 是 mineru.net /api/v4 的完整 bash 实现（369 行）
- `mineru-local` 通过软链 `scripts/mineru-parse.sh -> ../../mineru/scripts/mineru-parse.sh` 复用本脚本
- 修 bug / 加 feature 改这里

**为什么不删本 skill**：是 GitHub upstream clone（`.git/` + `.github/`），保留方便 `git pull` 拿官方更新。

**触发词分配（避免冲突）**：
- 用户说 "pdf 转 md / pdf2md / 解析 pdf / mineru" → `mineru-local`（双通道）
- 用户说 "mineru cloud / mineru.net / cloud API" → 仍可触发本 skill（少见情况）

## API 重要变更（2026-04-27 实测）

- **`model_version: hybrid` 已下线**（返回 `code -10002 "version field invalid"`）
- 推荐 `model_version: vlm`（默认，MinerU2.5 跑 cloud）或 `pipeline`
- mineru-parse.sh 默认 `MODEL=hybrid` 已不可用，要传 `--model vlm`（pdf2md 转发已默认 vlm）
